# Hensley Ukah - Portfolio Website

This is a modern, professional portfolio website for Hensley Ukah, an AI and software innovator.

## Description

The website is designed to showcase Hensley's skills, projects, and experience in a clean, minimalist, and mobile-first design. It includes the following pages:
-   Homepage
-   About
-   Skills & Projects
-   Insights
-   Contact

## How to View

To view the website, simply open the `index.html` file in your web browser. No special setup is required.

## Technologies Used

-   **HTML5**
-   **CSS3**
-   **JavaScript (ES6)**
